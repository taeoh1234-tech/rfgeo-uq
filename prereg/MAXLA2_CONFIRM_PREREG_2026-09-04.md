# 사전등록 — MAXLA2(max(z_LS, z_ACT), 양방향) 결합 교정기 확증 (2026-09-04)

작성: **실행 전·결과 확인 전**. `corrector_maxla.py`(선별)의 후속.

## 0. 무엇을 확증하나

MAXLA2 = 두 신호를 FIT 에서 표준화한 뒤 `z = max(z_LS, z_ACT)` (clamp 없음 — LS 의
음수쪽 보존), 다시 FIT 재표준화, `g = exp(kappa z)`. **사후 설계**(연구자 제안 → 선별 측정)
이므로 채택 전 확증이 필요하다. MAXRP 는 같은 관례(단방향 clamp)로 전 구간 지배당해
제외됐다 — MAXLA2 의 차별점은 양방향성이며 MAXLA1(clamp판)이 지배당함을 선별에서 확인.

**동결 kappa = 0.4** — 선별 근거: 에너지 7축(kf_1~3·cfo_2/3·TDL-A/C) 전부 관문(영역<=원반
20%) 안인 최대 kappa 이자 그 제약 하 평균 커버리지 최대(0.614). TDL 이 k=0.5 에서 이탈,
k=1.0 에서 3/7 로 붕괴. 조건부 편차 0.0196(k=0.5 의 0.0181 이 최소이나 관문 밖).

IND 0.907 / dev 0.0196 / sco_4 0.899 / delay_3 0.308 / occ 0.495.

## 3. 판정 조합 (모든 값 구간 — §72.8 교훈)

| M1 | M2 | 판정 |
|---|---|---|
| 4/4 또는 3/4 | PASS | ✅ **승격** — 에너지 계열 단일 손잡이로 채택 |
| 4/4 또는 3/4 | FAIL | 🟡 **부분** — TDL 제외 축만 채택, TDL 은 ACT 유지 |
| 2/4 | 무관 | 🟡 부분 — 통과 축만 개별 인용 |
| <= 1/4 | 무관 | 🔴 재검토 — 선별이 자원 우연 |

M3·M4·M5 는 보조 — 실패해도 승격을 막지 않되 그대로 보고하고 해당 주장에 한정 문구.
