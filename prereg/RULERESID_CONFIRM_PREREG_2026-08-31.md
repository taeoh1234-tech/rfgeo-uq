## 3. 점수와 절차 — 선별에서 고정, 변경 없음

```
in-dist(output_final/gcc_test.npz, 2000) 을 MAP/CAL/NEG 3분할 x 200 순열
MAP  : log(epi) ~ b0 + b1 log(featRMS) + b2 log(pk/far) + b3 log(반치폭)  회귀 적합
점수  s = (beta . x) - log(epi)        (규칙이 예측한 것보다 덜 불확실하다고 말할수록 큼)
p     = (1 + #{S_cal >= S_i}) / (n_cal + 1),   기권 = p <= alpha
1차 alpha = 0.05
```
⚠️ **회귀는 각 모델의 in-dist 에서 매 순열마다 새로 적합**한다(선별과 동일). 계수를 고정하지 않는다.
**임계를 사후에 조정하지 않는다.**

## 7. 알려진 한계 (실행 전 기록)

1. §73 과 같이 **선별·확증 모델이 같은 데이터셋으로 학습**됐다. 배제하는 것은 모델시드·생성시드·
   조건 사후선택 셋이고 **"이 데이터셋 고유의 성질"은 배제 못 한다.**
2. **후보 4종 비교(선택) 자체는 재현하지 않는다.** 여기서 확증하는 것은 *"`rule_resid` 가 확증
   자원에서도 작동하는가"*이지 *"4종 중 최선인가"*가 아니다. 후자를 확증하려면 4종을 전부
   확증 자원에서 재비교해야 하며 **이번 범위 밖**이다. → 보조로 `epi_low`·`psr_only` 를 함께 내되
   **판정에는 쓰지 않는다.**
3. `occ`·`TDL` 축이 held-out 이 아니므로 **조건 축의 독립성이 §73 보다 약하다.**

## 8. 실행 **전** 정정 (2026-08-31, 결과 미확인)

🔴 **내 사전등록의 내부 모순을 발견해 고친다.**
§2 는 *"`gen()` 보조 arm 을 두지 않는다"* 고 썼는데 §4 의 Q-B 는 **`TDL-C`(= `gen()` 조건)** 를
요구했다. 주 격자(npz 레벨)에 `TDL-C` 가 없으므로 그대로면 **판정 불능**이다.

**정정**: **Q-B 를 `kf_3` 단독**으로 한다(주 격자 20셀에서 판정 가능).
- `kf_3` 은 **C(`‖φ‖`)가 확증에서 0.051~0.091 로 침묵한 축**이므로 광범위성 검정의 취지를 그대로 만족한다.
- `TDL-A`·`TDL-C` 는 **모델 축 보조 arm**(4모델)으로 **보고만** 하고 **판정에 쓰지 않는다.**
  (둘 다 B 의 선별에 이미 쓰였으므로 held-out 도 아니다.)
- §6 판정 조합표의 Q-B 는 이 정의로 읽는다.

⚠️ 이 정정은 **어떤 결과도 보기 전에** 이뤄졌다. 본 절이 그 기록이다.
⚠️ §72.8 · §73 에 이어 **사전등록 문언 검토를 실행 직전에 한 번 더 하는 습관**이 필요하다는
세 번째 신호다.
