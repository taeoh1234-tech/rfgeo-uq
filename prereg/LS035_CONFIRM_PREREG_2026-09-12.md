# 사전등록 — LS@0.35 를 에너지 플래그·교정기로 확증 (2026-09-12)

작성: **실행 전·결과 확인 전**. `corrector_ls_fine.py`(선별)의 후속.
현직 `MAXLA2@0.4`(`MAXLA2_CONFIRM_PREREG_2026-09-04.md` 로 승격)를 교체할지 판정한다.

## 0. 무엇을 확증하나

**LS** = 오차 회귀 `z = X b_ls` (양방향, clamp 없음). 식 (3) 과 같은 세 곡선 통계를
**log 오차**로 재적합한 것. 현행 energy flag `MAXLA2 = max(z_LS, z_ACT)` 의 한 성분이다.

**동결 kappa = 0.35.** 🔴 **사후 선택임을 명시한다** — 0.05 격자(0.30~0.40)를
`corrector_ls_fine.json`(자원 h)에서 훑어 고른 값이다. 근거:
- 게이트(TDL-A 영역 **중앙값** <= 원반 20%) 를 만족하는 최대 kappa 는 0.375 이나,
- **kappa=0.40 은 자원에 따라 판정이 뒤집힌다** — 중앙값 19.2%(자원 g, 15셀) vs
  **21.1%**(자원 h, 5셀). 임계를 사이에 두고 갈리는 값은 동결 상수로 부적격.
- kappa=0.35 는 자원 h 중앙 **14.0%** 로 여유가 있고, 선별 복원값이 현직과 동급 이상.

**교체 동기 (선별 관측, 확증 대상 아님)**: LS 는 배정 계열 탐지에서 MAXLA2 를 크게
앞선다 — kf_3 0.574 vs 0.418 · TDL-A 0.736 vs 0.660 · TDL-C 0.738 vs 0.659
(`detector_binwise.json`, 모델 5, alpha=0.05). 이 탐지 우위는 `DETECTOR_UNIFY_PREREG_2026-09-04.md`
의 **D4(2차·"보고만")** 로 자원 k 에서 이미 재현됐다. ⚠️ **2차 등급이므로 본 확증의
1차 지표로 삼지 않는다.** 본 문서가 새로 확증하는 것은 **kappa=0.35 에서의 교정기 역할**이다.

⚠️ **기존 LS 확증은 이 kappa 를 덮지 않는다** — `normalizer_confirm.json`(09-02, 승격)과
`normalizer_reconfirm.json`(09-03)의 LS 동결 kappa 는 **0.5** 이고, 그 값은 현재 게이트
규칙에서 TDL-A 영역이 36~79% 로 탈락한다. 그래서 새 확증이 필요하다.

### B. 🔴 kappa=0.40 으로 채택 변경 — 등급을 낮춰 기술할 것

**연구자 판단(2026-09-12)으로 채택 kappa 를 0.40 으로 바꾼다.** 근거:
1. **게이트는 성능 지표가 아니라 배포 상수**이고, 논문 §5.3 의 주장은 이미
   *"any gate between them gives the same verdict"* 다. kappa=0.40 에서 최대 복원영역
   **18.5%** 와 최소 기권영역 **234.9%** 가 **12.7배** 떨어져 분리폭이 오히려 넓어진다.
2. 현직 MAXLA2 의 사전등록도 *"게이트 안 **최대 kappa**"* 로 골랐다. 같은 규칙을 LS 에
   적용하면 g·j 자원에서 0.40 이다.
3. 🔴 **내가 LS 에만 3자원(g/h/j) 기준을 적용했다** — 실측 확인 결과
   **RULE(0.6)·PHI(1.5) 는 g 계열에서만, MAXLA2(0.4) 는 h·j 에서만** 평가됐다.
   *"3자원 중 1개 실패"* 는 LS 에만 존재하는 정보이고 다른 arm 은 그 시험을 받은 적이 없다.
   ⟹ 그것을 배제 근거로 쓴 것은 불공정이므로 **철회**한다.

### C. 🔴 등급 — 논문에 이렇게 쓸 것

- kappa=0.35 는 **사전등록 held-out 확증**이다.
- kappa=0.40 은 **동일 검정의 사후 적용**이다 — 선택 시점이 결과 확인 후이므로
  *"held-out 확증"* 이라고 쓰면 안 된다. 쓸 수 있는 문장은
  *"kappa 는 에너지 계열 전 축이 게이트 안에 머무는 최대값으로 동결했고, held-out
  이동 자원에서 채널 계열 보정영역 중앙값은 17.8% 다"* 까지다.
- 🔴 **kappa=0.40 의 게이트 통과는 자원 의존적이다**: j 17.8% / g 19.2% / **h 21.1%**.
  논문에 h 를 인용할 의무는 없으나(다른 arm 에 대응 수치가 없어 비교 불가),
  **리뷰어가 물으면 이 부록으로 답한다.**
