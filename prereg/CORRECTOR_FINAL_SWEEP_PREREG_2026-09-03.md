# 사전등록 — 교정기 5종 x kappa 전면 스윕 (CORRECTOR-FINAL)

작성 2026-09-03, **실행 전·결과 확인 전**. 목적: 논문 5절의 최종 규칙을 정한다.
*"어떤 실패 유형을 어떤 교정기가 회복시키는가"* 를 결정하고, 유용성 없는 교정기를 제외한다.

---

## 1. 정규화기(교정기) 5종 — 방향은 정의가 정한다 (사후 선택 아님)

점수 `s = M / g`, `g = exp(kappa * z_hat)`, `z_hat` = FIT 집합 표준화.

| 지표 | z 원값 | 방향 | 왜 그 방향인가 |
|---|---|---|---|
| **LS** | `X b_LS` (곡선통계로 예측한 log 오차) | **양방향** | 오차 예측기이므로 축소·확대 둘 다 의미 있다 |
| **RULE** | `X b_rule - log sigma_epi` (규칙 잔차) | **단방향** `max(z,0)` | *"규칙보다 덜 불확실하다고 말한다"* = 이상 신호. 확대만 |
| **PHI** | `log ||phi||` | **단방향** | 활성 총량 과다 = 역전 표지(§70). 확대만 |
| **MAXRP** | `max(z_RULE, z_PHI)` (표준화 후) | **단방향** | 두 이상 신호의 합집합 |
| **ACT** | 합성곱 활성비율 | **단방향** | ||phi|| 의 앞단. 확대만 |

반대 방향 변형도 JSON 에 기록하되 **선정에는 쓰지 않는다**(사후 선택 방지).

## 2. kappa 격자

`0.0, 0.1, ..., 4.0` (41 값). kappa=0 은 정의상 기준(marginal elliptical CP)이다.
**붕괴 지점을 명시 보고한다** (아래 §5).

## 3. 자원 — 3분할로 교환가능성을 정확히 보장 (기존 규약과의 차이 명시)

기존 PART X~XII 스크립트는 `b` 를 `gcc_test` 에서 적합하고 같은 집합에서 평가했다
(분할 CP 의 "점수함수는 보정·시험을 보기 전에 고정" 요건을 엄밀히는 위반).
이번에는 **주 규약을 3분할로 바꾼다**:

| | 주 규약 (PRIMARY) | 보조 규약 (LEGACY, 기존 절과 비교용) |
|---|---|---|
| `b`, 표준화 | `calib[:2000]` | `gcc_test` (2000) |
| 보정 Q | `calib[2000:]` (2000) | `calib` 전체 (4000) |
| 분포 안 평가 | `gcc_test` (2000) | `gcc_test` (2000) |
| 교환가능성 | **정확** | 근사 |

둘 다 보고한다. **둘이 크게 다르면 기존 절들의 낙관을 정량화한 것**이므로 그 자체가 결과다.

**모델** 5개: m0~m3 + seed0. **이동 생성시드** 90001·90002(held-out).
**생성 조건** occ 0.05 / occ 0.20 / TDL-A / TDL-C x 새 세트 3개(g3~g5).

## 4. 비교 축 — 이동 축 + **분포 안 SNR 구간**

- **분포 안**: 전체 + SNR 6구간 (`[-inf,-5) [-5,0) [0,5) [5,10) [10,15) [15,inf)`).
  저SNR 구간은 marginal CP 가 명목을 크게 밑도는 곳이고, **Mondrian 은 SNR 라벨로** 이를 고친다.
  ⟹ Mondrian 을 **참조 arm**(라벨 필요)으로 같은 표에 싣는다.
- **이동**: `delay_0..3, kf_0..3, cfo_0..4, sco_0..4, snr_0..2` (21) + 생성 4조건.

**채점 대상 축** = 기준(kappa=0) 커버리지 **< 0.88** 인 축. 나머지는 가드레일로만 쓴다.

## 5. 판정 규칙 (전부 실행 전 고정)

**유용성 관문**: 영역 **중앙값** / 탐색원반(201.06 km^2) <= **0.20**.
**회복도** `R = clip((cov - cov_base) / (0.90 - cov_base), 0, 1)`, **관문 실패 시 R = 0**.
  (형식상 커버리지를 올려도 영역이 무용하면 회복이 아니다 — §67.2)

**가드레일 (FALSIFIER)** — 하나라도 깨지면 그 (arm, kappa) 는 후보에서 제외:
  G1 분포 안 전체 커버리지 ∈ [0.87, 0.93]
  G2 NULL 축 `sco_4` 커버리지 >= 0.85
  G3 분포 안 영역 중앙값 <= 기준의 **3배**

**붕괴 (조기 종료 보고용)**: 다음 중 하나가 처음 발생하는 kappa 를 그 arm 의 붕괴점으로 기록한다.
  C1 G1 위반 / C2 분포 안 영역 > 원반 20% / C3 **모든 이동 축**이 유용성 관문 실패
  (계산 비용은 kappa 에 대해 무시 가능하므로 전 격자를 계산하되, 붕괴점 이후 값은 판정에서 제외한다.)

**arm 별 최선 kappa**: 가드레일 통과 + 미붕괴 kappa 중 **채점 축 평균 R** 최대.
**축별 승자**: 그 축에서 R 최대인 arm.
**제외 규칙**: 최선 kappa 에서 **어떤 축에서도 승자가 아니고** 평균 R 이 최고 arm 대비 **0.10 이상 낮은** arm 은 제외.

## 6. 사전 예측 (실행 전)

| # | 예측 |
|---|---|
| **P1** | 분포 안 **저SNR 구간**의 승자는 **LS 또는 ACT** (오차/활성 크기를 직접 읽는 지표) |
| **P2** | `occ 0.05` 의 승자는 **PHI** |
| **P3** | `delay_3` 의 승자는 **RULE 또는 MAXRP** |
| **P4** | 어떤 arm 도 **채점 축의 과반에서 승자가 되지 못한다** (단일 교정기로 전부 못 덮는다) |
| **P5** | 5종 중 **최소 1종이 제외 규칙에 걸린다** |
